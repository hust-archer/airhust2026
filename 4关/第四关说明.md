# 第四关补充 —— 目标不可达问题

> 本文是《第三关说明》的补充，只讨论讲义 Stage 4 提到、但第三关没有展开的**目标不可达问题**。  
> 人工势场法的基本原理、代码实现、`collision_1` / `collision_2` 两个场景的实测数据，均见《第三关说明》，此处不重复。

---

## 一、什么是目标不可达

目标不可达（Goals Non-Reachable with Obstacles Nearby，简称 GNRON）指这样一种失败：

**目标点本身落在障碍物的斥力作用范围之内**，飞机越接近目标，引力越小、斥力反而越大，两者在离目标还有一段距离的地方就平衡了。

数学形式一样（都是合力为零的平衡点），但触发条件和修法完全不同。局部最优要靠"打破对称或绕路"解决，目标不可达要靠"削弱目标附近的斥力"解决。

---

## 二、机理与平衡条件

按讲义的三段斥力模型，设飞机到障碍的距离为 `ρ`、到目标的距离为 `d_goal`，则平衡点满足：

```text
k_a · d_goal = F_rep(ρ)
```

关键在两边随位置的变化方向相反：

- 飞机越靠近目标，`d_goal` 越小，`k_a · d_goal` 这条引力也越小
- 如果目标在障碍附近，靠近目标的同时往往也在靠近障碍，`ρ` 变小，`F_rep` 反而变大

于是一定存在某个位置让两边相等。只要这个位置上的 `d_goal` 还大于到点阈值（本工程是 0.3 m），飞机就会停在那里不动。

---

## 三、为什么本关的两个场景都没有触发它

`collision_1` 和 `collision_2` 里，目标都是 `(6.0, 0.0)`：

- 柱子位于 `x ≈ 3.05`，与目标的水平距离约 **2.95 m**
- 而 `R_outside = 1.6`，是斥力开始作用的边界

也就是说，飞机进入最后接近段时，柱子已经在身后将近 3 m，`ρ > R_outside`，`F_rep` 恒等于 0，势场里只剩引力一项，能正常收敛到 0.3 m 以内触发降落。

---

## 四、解决方法

### 4.1 目标邻域衰减斥力

认定"离目标足够近时逐步削弱避障"，让斥力随 `d_goal` 线性衰减，到目标处归零。

```cpp
// 目标附近按比例削弱斥力：越近越弱，但不会突然消失
float d_goal = sqrt((target_x - pos.x) * (target_x - pos.x)
                  + (target_y - pos.y) * (target_y - pos.y));
float w = d_goal < 0.8f ? (d_goal / 0.8f) : 1.0f;
F_c *= w;
```

`0.8` 是衰减半径，取值受两头夹：

- 要明显大于到点阈值（本工程 0.3 m），否则飞机还没到就已经开始削弱
- 又要小于 `R_outside`（1.6 m），否则削弱作用会蔓延到整个避障区

### 4.2 停滞检测 + 逃逸动作

连续若干帧位置变化小于阈值、且距目标仍大于阈值，就判定卡住，切换到固定方向绕行几秒。

```text
if (|Δpos| < 0.05 m 持续 1 s) && (d_goal > 0.3 m)
    → 沿锁定方向侧移 2 s，然后恢复
```
